## 三、破解了什么

原版的授权链路是「登录 → 取 token/c_id → 查到期时间 → 写会员标记」四段串联，本版按下面的方式摘掉闸门，其余逻辑保持原样：

| 层 | 位置 | 处理 | 效果 |
|---|---|---|---|
| 入口注入 | 程序入口 | 跳板到代码洞，先执行原入口再重刷状态 | 启动即进入主界面，跳过登录窗 |
| 探测后跳板 | `query_login` / `fetch_auth_state` 返回处 | 探测到未登录 / 未充值则跳板重刷 | 不弹登录、不弹充值 |
| 解析降级拦截 ×3 | 授权解析函数内 3 处 | 解析失败不降级到「未授权」分支 | 功能闸门保持打开 |
| 清零 NOP ×2 | 会员标记写入点前 | 2 处 `NOP` 掉「置 0」写入 | `is_vip` 恒为 1 |

写入内容只有一个 `is_vip = 1`；`token`、`c_id`、到期时间等字段一律保留服务端真值，所以会员中心、下单类点击行为与正版一致（不会白屏、不会点了没反应）。

## 六、注意

- **别让它自动升级**：程序带更新逻辑，自动更新会把 exe 覆盖回正版，补丁随之失效；真被覆盖就重新下载本仓库文件替换。
- 它会往 `文档\CleanupSys.ini` 写 token，删掉不影响使用。
- 想恢复原版：去官网或原安装包取回 `C盘清理精灵.exe` 覆盖即可。
- 连续快速点击、清理任务进行中再点别的功能，正版本身也可能「未响应」，与改包无关。
- 仅供个人学习研究与本地测试使用，请勿用于商业分发。
